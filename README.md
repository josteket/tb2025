# ООО «Титаны будущего» — статический футуристичный сайт

Продакшн-макет корпоративного сайта в формате чистого HTML/CSS/JS. Архитектура адаптирована под классический web-хостинг: достаточно
загрузить содержимое репозитория на сервер, и сайт заработает без Node.js и сборки.

## Что внутри

- **index.html** — единая страница с разделами «Главная», «О компании», «Кейсы» и «Контакты».
- **assets/css/styles.css** — тема, сетка, glassmorphism-эффекты, адаптив и доступность.
- **assets/js/** — модульный JavaScript для анимаций, 3D-сцены, данных и логики интерфейса.
- **public/** — текстовые заглушки для изображений/фавикона (замените на реальные ассеты).
- **robots.txt**, **sitemap.xml** — SEO-заготовки для поисковиков.

Основные эффекты:

- прелоадер с «цифровым туманом» и глитч-силуэтом шлема;
- Three.js-сцена с процедурным шлемом, пост-эффектами (bloom + chromatic aberration) и частицами;
- GSAP + ScrollTrigger-анимации заголовков, карточек и фоновых градиентов;
- счётчики фактов, модальные окна кейсов, кнопка «Наверх» с прогрессом;
- курсорный трейл (отключается для `prefers-reduced-motion`).

## Быстрый старт

1. Склонируйте репозиторий или скачайте архив.
2. Загрузите файлы на ваш хостинг в корневую папку сайта.
3. Откройте `https://ваш-домен/index.html` — проект готов к работе.

Локально можно просто открыть `index.html` двойным кликом (Chrome/Edge/Firefox). Для корректной загрузки модулей рекомендуется
использовать лёгкий статический сервер (`python -m http.server`, `npx serve` и т.п.).

## Как добавить ассеты

1. **Изображения и иконки**. Поместите реальные файлы в директорию `public/` и замените пути `/public/placeholder.svg` в HTML/JS на
   нужные URL. Это касается логотипа, кейсов, карты и Open Graph-превью.
2. **Логотип**. Замените `public/placeholder.svg` на `public/logo.png` и обновите `index.html`, указав новый путь. В README оставлена
   ссылка на будущий логотип клиента.
3. **3D-модели**. Сейчас используется процедурная геометрия. Чтобы подключить реальный шлем, загрузите GLB/GLTF в `public/models/` и
   обновите функцию `createHelmet()` в `assets/js/threeScene.js`, заменив её на загрузку GLB (оставлен комментарий «Заменить на реальный
   GLB в public/models/»).
4. **Favicon**. Положите настоящий файл `public/favicon.ico` и обновите тег `<link rel="icon">` в `index.html`, если меняете формат.

## Структура данных

- `assets/js/data.js` содержит массивы `stats`, `cases` и объект `featureFlags`.
- Чтобы добавить кейс, добавьте объект `{ title, summary, result, tags, image }` в `cases`. Модальное окно подхватит данные
  автоматически.
- Статистические плашки (факты) задаются массивом `stats`.

## Управление анимациями и производительностью

`featureFlags` в `assets/js/data.js` позволяют гибко настраивать эффекты:

```js
export const featureFlags = {
  enableParticles: true,      // частицы и звёздная пыль в 3D-сцене
  enableBloom: true,          // пост-обработка (bloom + хром. аберрация)
  enableCursorTrail: true,    // трейл курсора
  enableScrollAnimations: true // GSAP ScrollTrigger-анимации
};
```

- Системная настройка `prefers-reduced-motion` автоматически отключает тяжёлые эффекты и скрывает 3D-сцену.
- При необходимости можно вручную выставить флаги в `false`, если сайт должен работать в «лёгком» режиме.

## Настройка дизайна

- Цветовая палитра задаётся CSS-переменными в начале `assets/css/styles.css` (`--bg`, `--neon-cyan`, `--accent-red` и др.).
- Шрифты по умолчанию используют системные варианты; добавьте `@font-face` в `styles.css`, если хотите подключить Inter / JetBrains Mono
  локально.
- Стеклянные панели (`.glass-panel`), карточки кейсов и фоновые сетки можно настроить через одноимённые классы.

## SEO и мета-данные

- В `index.html` прописаны базовые теги Open Graph и Twitter. После деплоя обновите `https://example.com/` на боевой домен.
- Файлы `robots.txt` и `sitemap.xml` находятся в корне; отредактируйте `Sitemap:` и `<loc>` под реальный адрес.

## Деплой

- **Обычный shared-хостинг / VPS** — скопируйте файлы в корень сайта (`public_html`, `/var/www/html` и т.п.).
- **GitHub Pages / Cloudflare Pages / Netlify** — используйте режим «статический сайт», указав корнем репозиторий.
- **Vercel** — создайте проект как «Static Site» и укажите команду билда `none`; Vercel будет раздавать `index.html` из корня.

## Подсказки для арт-команды

- Все изображения и модели пока заменены на текстовые заглушки. После утверждения дизайна загрузите брендовые ассеты в `public/`.
- В hero-сцене оставлен процедурный шлем; при появлении логотипа клиента замените геометрию на экспортированный GLB.
- Если требуется облегчённый вариант (например, презентация без 3D), достаточно отключить флаги и удалить подключение Three.js в
  `assets/js/main.js`.

Готово! Персонализируйте ассеты, обновите доменные ссылки — и «Титаны будущего» будут готовы к бою.
