# ООО «Титаны будущего» — статический кибер-лендинг

Полностью автономная версия лендинга «Титаны будущего» для любого веб-хостинга. Достаточно загрузить файлы на сервер — никакие
сборки, зависимости и серверные рантаймы не нужны. Вёрстка, анимации и 3D работают целиком на HTML/CSS/JavaScript.

## Структура проекта

```
index.html          — основная страница с секциями Hero/О компании/Кейсы/Контакты
assets/
  css/main.css      — палитра, сетка, эффекты, адаптив и состояния
  js/main.js        — GSAP-анимации, 3D-сцена Three.js, счётчики и интерактивы
  images/           — SVG-заглушки для кейсов и карты
  icons/            — SVG-заглушка фавикона
```

Все библиотеки подгружаются с CDN:
- **GSAP + ScrollTrigger** — скролл-анимации и фоновые градиенты.
- **Three.js + OrbitControls + пост-эффекты** — процедурный шлем, частицы и bloom.
- Шрифты **Inter** и **JetBrains Mono** — через Google Fonts (можно заменить на локальные).

## Как развернуть

1. Скопируйте репозиторий или архив папки на компьютер.
2. Откройте `index.html` прямо из файловой системы (двойной клик) — сайт работает локально.
3. Для продакшена залейте весь каталог `tb2025` в корень любого статического хостинга (FTP, S3, GitHub Pages и т.д.).

Дополнительно можно запустить простой сервер для теста:

```bash
python3 -m http.server 5173
# затем откройте http://localhost:5173
```

## Как добавить ассеты

1. **Логотип**: замените вёрстку логотипа в шапке или добавьте реальный `logo.png` рядом с `index.html`, поправив `index.html` на
   `<img src="logo.png" alt="Логотип" />`. Текущая версия использует текстовый логотип TF.
2. **Изображения и иконки**: положите реальные файлы в `assets/images/` и обновите пути вместо `/assets/images/placeholder.svg`.
3. **3D-модель**: в `main.js` шлем собирается процедурно. Если есть GLB по фирменному логотипу, положите его в `assets/models/`
   (создайте папку) и замените блок `createHelmetGeometry` на загрузку через `GLTFLoader` из Three.js. В комментариях оставьте
   пометку «Заменить на реальный GLB».
4. **Favicon**: замените `assets/icons/favicon.svg` на настоящий ICO или PNG и обновите тег `<link rel="icon">`.

## Анимации и производительность

- Поддержка `prefers-reduced-motion`: тяжёлые эффекты (частицы, bloom, курсорный хвост) отключаются автоматически.
- `main.js` содержит функции `setupGsapAnimations`, `initHeroScene`, `setupCursorTrail` — их можно выключить или упростить при
  необходимости.
- Для слабых устройств сократите `particleCount` в `initHeroScene` и уменьшите интенсивность glow.

## Контент и кастомизация

- Все кейсы описаны в массиве `cases` внутри `assets/js/main.js`. Добавьте или измените элементы `{ title, summary, result, tags, image }`.
- Тексты секций находятся непосредственно в `index.html`. Проект полностью русифицирован.
- Цветовая схема и эффекты заданы переменными в начале `assets/css/main.css`. Измените `--bg`, `--accent-red`, `--neon-cyan` и др.,
  чтобы адаптировать палитру.

## Деплой и поддержка

- **FTP / shared hosting**: загрузите папку `tb2025` (или её содержимое) на сервер. Главный файл — `index.html`.
- **Vercel / Netlify / Cloudflare Pages**: создайте новый проект как «статическая директория» и укажите корневой путь.
- **GitHub Pages**: включите Pages в настройках репозитория, указав ветку с файлом `index.html` в корне.

## Замена 3D-ассета (GLB)

1. Поместите `helmet.glb` в `assets/models/`.
2. Подключите `GLTFLoader` в верхней части `assets/js/main.js`:
   ```js
   import { GLTFLoader } from "https://unpkg.com/three@0.161.0/examples/jsm/loaders/GLTFLoader.js";
   ```
3. Внутри `initHeroScene` замените вызов `createHelmetGeometry()` на загрузку модели:
   ```js
   const loader = new GLTFLoader();
   loader.load("assets/models/helmet.glb", (gltf) => {
     const helmet = gltf.scene;
     helmet.scale.setScalar(1.5);
     scene.add(helmet);
   });
   ```
4. Удалите или отключите процедурную геометрию, если используете реальный ассет.

После замены изображений и модели сайт будет готов к бою на любом статическом хостинге.
